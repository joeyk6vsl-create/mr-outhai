# Arduino ສອບໃຫ້ຜ່ານ

ເວັບທົບທວນກ່ອນເສັງ Arduino ພາສາລາວ ທີ່ໃຊ້ plain HTML, CSS ແລະ JavaScript. ເປີດ `index.html` ຫຼື deploy ກັບ GitHub Pages ໄດ້ໂດຍບໍ່ຕ້ອງ build.

## ເນື້ອຫາ

- Arduino basics: `setup()`, `loop()`, digital/analog I/O ແລະ Serial Monitor
- TMP36 analog temperature ແລະສູດແປເປັນ °C
- ຄວາມຕ່າງລະຫວ່າງ TMP36, DHT11 ແລະ soil moisture
- PIR motion sensor
- IR remote ດ້ວຍ Arduino-IRremote v4
- HC-SR04 ultrasonic distance sensor
- 6 code labs, flashcards ແລະ quiz 50 ຂໍ້ພ້ອມສະເຫຼີຍ

ຄວາມຄືບໜ້າ ແລະຄະແນນຖືກບັນທຶກຢູ່ໃນ browser ດ້ວຍ `localStorage`.
